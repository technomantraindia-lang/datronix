DaTo DASG3 Key Programmer

Key Programmer Remote Maker

Remote Maker with Super Chip and Smart Keys

DAS723 PRO ULTRA Compatible

The DaTo DASG3 Key Programmer Remote Maker identifies car key chips, generates chip models from super remotes, reads remote control frequency and generates remote control devices for different car models.

  • Supports 8A, 8C, 8E, 4C, 4D, 4E, 48 and 7935-7939 chips
  • Supports 11, 12 and 13 chip types
  • Converts most car model chip types
  • Supports separate matching to achieve vehicle startup
  • Reads transponders and generates transponders
  • Detects key remote frequency and ignition switch coil signal
  • Can be used with DAS723 PRO ULTRA

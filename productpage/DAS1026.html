DaTo Bluetooth OBD2 Scanner

Bluetooth OBD2 Scanner DAS1026

Bluetooth OBD2 Scanner Code Reader with Full Systems

Bluetooth 5.0

The DaTo DAS1026 is a compact wireless OBD II diagnostic scanner that reads and clears fault codes, shows readiness status, monitors live data and supports enhanced OBD2 testing through Android devices.

  • Available for most vehicles produced after 1996 with OBDII protocol
  • Supports CAN, J1850PWM, J1850VPM, ISO9141 and KWP2000 protocols
  • Supports Android devices with Bluetooth OBD2 scanner app
  • Reads and clears trouble codes quickly
  • Displays live oxygen sensor data and real-time data monitoring
  • EVAP system test support for fuel-system leak checks
  • Compact wireless design for easy portable diagnostics

Description

Product Overview

  • Wireless OBD II diagnostic scanner for quick vehicle fault checks.
  • Reads and clears fault codes, displays I/M readiness and views past and present vehicle data.
  • Real-time data monitoring helps track vital engine parameters while driving.
  • Displays live oxygen sensor data for better emissions and engine diagnostics.
  • EVAP system testing helps identify fuel-system leaks.
  • Diagnostic reports can be printed through a PC.
  • Compact and portable design makes it easy to diagnose issues on the go.
  • Regular software updates help keep compatibility with newer vehicle technologies.
